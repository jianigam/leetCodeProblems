# leetCodeProblems
DSA Practice Repository

This repository contains my practice solutions for Data Structures & Algorithms problems.

For a single problem, multiple approaches may be present, including:

TLE / failed attempts

My Approach

Brute force solutions

Better or optimized approaches

Final optimal solution

The goal of this repository is to document the learning and optimization process, not just the final answers.

Repository Structure

Each problem is stored in its own folder.

Problem-Name/
├── tle.cpp
├── brute.cpp
├── better.cpp
├── optimal.cpp


Not every problem contains all files; only the approaches actually tried are included.

Why Multiple Approaches?

To understand why certain solutions fail

To learn how to optimize step by step

To improve problem-solving skills

To prepare for interviews and online assessments

I intentionally keep brute force and TLE solutions for learning purposes.

Language Used

C++
